# Stage24: all-family blocking ADC scans and module cleanup

Ordered blocking ADC scans now cover all 13 current families. F002/F003/F020/F030/A030 support up to four slots; the remaining families support up to eight. Owned and borrowed channels preserve caller order. Classic variants use one common sample time and exclude buffered/internal multi-slot scans. L010/L011/L012 support per-slot sample times; L012 preserves sibling and shared analog ownership. Continuous, IRQ, DMA, externally triggered scans and coupled dual-ADC modes remain incomplete. Existing single-conversion APIs remain available.

UART configuration and the CW32 shared-vector block now live in flat usart.rs. The two ADC clock helpers live with their sequence owner. CRC is flat crc.rs with direct PAC access and no register-holder wrapper. Five moved helper bodies remain byte-identical; the CRC comparison accounts for all initialization, reset, feed-width, result and Drop operations. Public APIs and MMIO ordering are preserved. Substantial timing solvers and distinct ownership APIs remain separate. Other old timer/RCC register abstractions remain explicit future cleanup work.

The source-import workflow now exports review-only register candidates without requiring already-curated enums or HAL capabilities. Actual import passed all 13 families, emitted 136 templates and no chip files, and left all 877 normal generated files byte-identical. Direct library callers should use fresh candidate directories; existing files are never pruned.

Compact packaging excludes historical logs, firmware and compressed predecessor snapshots while retaining current source, provenance and receipt summaries. The distribution guard now inspects supported nested ZIP/TAR/compressed containers in memory under explicit budgets and rejects known prohibited content. This is not universal copyright scanning or legal clearance for earlier archives.

Final combined verification passed 108 ordinary ARM library builds, 97 genuine firmware links, all 54 PAC selections and 216 metadata checks. Source/schema/provenance checks passed, including 35 provenance cases. No HAL tests were restored and no firmware was executed. A stale historical L012 whole-file proof was reconciled by preserving its exact authored snapshot and independently checking the current ISR fields/access; the original access-only correction remains reproducible.
