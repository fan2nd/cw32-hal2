# Native low-power LSE implementation boundary

This candidate extends the accepted L010 shared hardware shape to exactly CW32L011K8T6/K8U6 and CW32L012C8T6/C8U6. Each family is qualified by its own source records in lse-l011-qualification.json and lse-l012-qualification.json. The common leaf is lse_native_low_power.rs; family-specific RTC/UART/LPTIM/I2C/GPIO operations remain direct typed PAC branches, within the central RCC gate/ownership contract.

The schema migration is deliberately explicit and breaking: native_l010 becomes native_low_power. The nine existing L010 facts, routes and inherited_legal/36080Hz policy are preserved. monitor_reference and detector_margin_lse_edges are mandatory; no default or old-name alias is supplied. The optional factory address serializes None as null. Exact-family validators require None for L010 and the explicit own LSI halfword 0x001007C2 for L011/L012. It is never inferred from HSI calibration. Prior sixteen active-LSE profiles retain None. Adapted metapac provenance and the complete historical replacement_review remain intact; legal clearance is false.

L011 uses factory-reference maximum 41000Hz from its datasheet; L012 uses 36080Hz. Both retain the narrower legal-source platform boundary, source/board environment declaration, stable factory-matching native TRIM and frozen TRIM/WAITCYCLE. Factory matching is provenance/matching, not a frequency or jitter measurement. The hardware128-edge/256-LSI-cycle threshold and the one-edge engineering margin are separate facts. None performs no new LSE admission/calibration. No LSI trim/startup/recovery is added by the LSE leaf.

StartupOnly requires inherited CCS0 and supplies only startup-count readiness. MonitoredExistingRoutes deliberately preserves active fault capture/IRQ/brake/timer routing, including effects before an error. It does not promise unchanged observer state during a fault. New starts reject central source/readiness/IRQ/lock ownership, inspect own configuration-only consumers, and recheck admission before commit. Exact live reuse does not restart, retune or change monitoring. L011/L012 reject raw PINLOCK reuse; L010 retains its accepted behavior. Inherited/requested pads remain monotonic on every outcome.

Only GPIOC is opened for new-family pad inspection; bounded central RCC restoration does not undo whole-bank sampling/filter/event progress. L012 PC13 RTC_OUT is checked inside that admitted window. GPIOA/B/F output routes and L012 UART3 are checked only if already operational and reset-released. Closed gates, retained timer roots/cascades, external recipients and inaccessible UART3 remain unverified functional handover conditions. Unresolved L012 UART3 gate and BTIM/ATIM mapping conflicts are preserved explicitly. They are not new safe-Rust memory-safety duties. No dormant timer gate, reset, RTC unlock or flag clearing is used as an inspection primitive.

## RTC activation and divider transition

The native CalendarClock is HsiOsc/Lse; existing one-argument HSIOSC acquisition remains. L011/L012 use 96MHz nominal HSIOSC, own-source maximum 97.92MHz and default divisors120/400000. LSE uses 32768Hz nominal, SOURCE0 and actual divisors1/16384 (encoded PSC1=0/PSC2=0x3fff), giving nominal2Hz TICKCLK and1Hz calendar transitions. Attach verifies selected source, actual first-stage ceiling, nominal factor pair, disabled compensation and exact LSE divisors; it performs no source or calendar repair.

Own L011 RM PDF140/152/154 and L012 CN PDF202 / EN PDF219/221 establish selected-source PSC1/PSC2, RTCCLKD<=1MHz and WAIT-based native access with no ACCESS field. New-family initialization drains WAIT before DATE, rejects retained controls/ISR, and rechecks health/ownership. It stages the first divisor to max(incoming divisor, requested divisor), verifies it, switches/verifies SOURCE, then applies/verifies the final requested pair. This never increases incoming RTCCLKD and bounds the target before selection:97.92MHz/120=816kHz, while accepted LSE maximum<=100kHz with divisor1. Thus a legal incoming source stays within the ceiling throughout; this is not retrospective repair of an already illegal entry. Each completed bounded wait is followed by source-health validation. Old L010/prior16 initialization order is preserved.

Later calendar activation still needs downstream root ownership within the requested RTC operation or absent independent recipients. It is not established by oscillator-pad ownership, START0 or reserved RTC1HZ0. Failure can leave staged division/source selection and consumes no elapsed-time continuity promise. StartupOnly loss may remain invisible. No fallback, restart or fault recovery is supplied.

Software generation/build/ELF receipts and the independent runtime review are separate acceptance evidence. No board electrical, crystal startup distribution, per-window jitter or physical fault-timing tests are claimed.
