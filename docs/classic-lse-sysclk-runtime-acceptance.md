## Actual cold and reuse sequences

1. The public try_init path validates configuration before taking singletons. The outer RCC initializer reserves the inherited/requested union of LSE pads before the backend. Within configure, the same preflight precedes source mutation and distinguishes exact enabled reuse from fresh admission. No new oscillator or independent source configuration is added.
2. The new target extends target_lsi to permanent_lsi for exactly the LSE target. Its inherited PLL admission requires an enabled/stable PLL with a recognized reference; HSI-fed retained PLL additionally requires already-matching trim and divider. Existing AWT/LVD HSI-trim exclusions and explicit HSE consumer/exact-match rules remain in place.
3. Conservative Flash latency and monotonic bus guards are established first. prepare_factory_lsi is called before the first CR1 write. The complete LsiColdSnapshot, prepare_factory_lsi, wait_factory_lsi and modify_sources bodies remain byte-identical to Stage56 (external-evidence/stage57/lse-runtime-review/draft1-baseline-check.json).
4. The cold factory-LSI path reads the raw factory halfword, rejects erased 0xffff, accepts zero, excludes live nonmatching or contradictory direct/mirror state, and performs two full consumer passes plus the final use-edge pass. A coincidentally matching stopped trim does not bypass admission. WAIT/reserved bits remain exact, and only admitted TRIM can change. Generated RTC/AWT/UART/MCO/GPIO/PB11 inspections are unchanged. The final public init documentation explicitly extends the whole-bank functional handover to this new target.
5. The requested/selected matching LSI path performs no trim or WAIT write. In-flight matching requests must become ready within the bounded poll budget. Both readiness indications and the frozen parameter mask are checked. A running LSE with stopped/unadmitted LSI rejects through the unchanged cold exclusion rather than stopping LSE or weakening the reference proof.
6. The first CR1 write asserts HSIEN, LSIEN and all mandatory CCS bits. Factory LSI is verified before HSI switching or any requested external source starts. All later backend source writes receive permanent_lsi=true; the unchanged LSE leaf preserves the already-asserted request. The optional HSI calibration bridge still selects the admitted LSI, stops/calibrates/restarts HSI, and returns to HSI. The branch cannot disable the inherited PLL or the detector request.
7. Inherited PLL leaves through confirmed HSI. A retained HSI reference cannot be retuned; HSE references are preserved under the established ownership conditions. Early LSE start occurs only after explicit HSI selection and factory-LSI revalidation. Fresh startup repeats the existing full source/consumer/pad admission; exact running reuse verifies without pad/source retuning or unlock.
8. The startup loop checks LSE failure flags before accepting readiness. The new verify_tree adds the independent detector/mandatory-CCS, HSI, preserved PLL and relevant HSE checks to the unchanged LSE config/pad/fault predicate, including after gate handshakes.
9. With HSI explicitly selected, one keyed CR0 operation installs final divisors, readback confirms HSI/dividers, and Flash latency covers max(declared LSE HCLK, configured retained/fallback HSI HCLK). The chosen direct-source cache/prefetch policy is preserved. A second complete tree check precedes one final LSE selection. No later CR0/divider/source-control write exists in the new returning branch.
10. Final tree/pad/monitor checks, Flash readback and final LSE selector/divider readback precede freezing the monitor parameters and returning Clocks. The caller publishes clocks only after configure succeeds. The monitor descriptor stores every LSI bit except the generated read-only STABLE mask; later classic LSE health requires mandatory CCS, permanent LSIEN, direct/mirror stability, and unchanged parameters.

## Failure and ownership edges

Every failing Result in the new branch exits before its successful Clocks return. The outer reservation union is not released. No new flag clear, reset, retry, oscillator disable or rollback was added. Gate inspection can fail after partial gate activity; trim/source/Flash/guard changes can remain. Poll counts are not wall-clock deadlines, and source readiness can arrive after a timeout. The final reads detect selected observable failures but cannot prove continued CPU progress or prevent later loss.

The no-later-selector-RMW order is a bounded new-path improvement. It does not weaken or reinterpret the accepted contract in rcc/mod.rs excluding guaranteed recovery from arbitrary asynchronous source loss during initialization register read/modify/write. The final contract explicitly says frozen LSE SYSCLK/HCLK/PCLK bounds and dependent timing assumptions become invalid after loss/fallback; neither HSI fallback nor an RTC source transition republishes them.

## Compatibility boundaries

Old targets continue to evaluate permanent_lsi exactly as target_lsi. The new early block and dedicated final sequence are guarded only by target_lse. Old late LSE startup remains in place. The new shared-leaf monitor hook returns true from its empty frozen record before any MMIO, so no old auxiliary-LSE path acquires a new detector calibration obligation. The timing reviewer independently reports a byte-identical old configure projection after removing only new-target code and reducing the common Boolean. General Lse::bounds is unchanged; target-only margin is outside it. Final cfg and all 23 old auxiliary-package evidence remain the specialist's scope.
